# Keyboard Master Binary Releases

This directory contains the split binary installer for **Keyboard Master v0.8.0**.

## How to recombine & run the Installer (.exe)

On Windows, open PowerShell or Command Prompt in this folder and run:

```cmd
copy /b Keyboard-Master-Setup-v0.8.0.zip.001 + Keyboard-Master-Setup-v0.8.0.zip.002 Keyboard-Master-Setup-v0.8.0.zip
```

Then extract `Keyboard-Master-Setup-v0.8.0.zip` and run `Keyboard Master-0.8.0 Setup.exe`!
