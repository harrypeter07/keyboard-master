# Keyboard Master Binary Releases

This directory contains the split binary releases for **Keyboard Master v0.8.0**.

---

## 1. Ready-to-Use Standalone App (`Keyboard Master.exe`)

No installation required! To extract the standalone executable folder:

Run this command in Command Prompt or PowerShell inside this `releases/` directory:

```cmd
copy /b Keyboard-Master-Standalone-v0.8.0.zip.001 + Keyboard-Master-Standalone-v0.8.0.zip.002 + Keyboard-Master-Standalone-v0.8.0.zip.003 Keyboard-Master-Standalone.zip
```

Then extract `Keyboard-Master-Standalone.zip` and run **`Keyboard Master.exe`** directly!

---

## 2. Windows Setup Installer (`.exe`)

To combine the Windows Setup installer wizard:

```cmd
copy /b Keyboard-Master-Setup-v0.8.0.zip.001 + Keyboard-Master-Setup-v0.8.0.zip.002 Keyboard-Master-Setup-v0.8.0.zip
```

Then extract `Keyboard-Master-Setup-v0.8.0.zip` and run `Keyboard Master-0.8.0 Setup.exe`!
